📊 เชื่อมต่อ Google Sheets
สถานะการเชื่อมต่อ: ⚠️ ยังไม่ได้ตั้งค่า URL

วางลิงก์ Web App URL จาก Google Apps Script ด้านล่าง เพื่อรับคะแนนดาวและคอมเมนต์จากผู้เล่นเข้าสู่ Google Sheets โดยอัตโนมัติ (รองรับทั้งการใส่ในช่องนี้หรือใส่ในโค้ด DEFAULT_GAS_URL)

📘 วิธีสร้างลิงก์ Google Sheets (คลิกเพื่อดูขั้นตอนและโค้ด)
  1. เปิด Google Sheets สร้างชีตใหม่
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมออก แล้ววางโค้ดด้านล่างนี้ลงไป จากนั้นกด บันทึก (💾)
  4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)
  5. เลือกประเภทเป็น เว็บแอป (Web app) ตั้งค่าผู้มีสิทธิ์เข้าถึงเป็น ทุกคน (Anyone) แล้วกด Deploy
  6. คัดลอก URL ของเว็บแอป มาวางในช่องด้านบนแล้วกดบันทึก
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["วันเวลา", "ชื่อเล่น", "โหมดที่เล่น", "คะแนน", "จำนวนดาว", "ความคิดเห็น"]);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString("th-TH"),
    data.nickname || "ไม่ระบุชื่อ",
    data.mode || "-",
    data.score || 0,
    data.stars || 0,
    data.comment || ""
  ]);
  return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}

❓ วิธีเล่น & การควบคุม

1. จัดเรียงบล็อกให้เต็มแถวแนวนอนเพื่อทำคะแนนและเคลียร์แถว

2. ทุกครั้งที่เคลียร์แถวได้ จะเปิด การ์ดความรู้ เรื่อง "สำรวจก่อนสร้าง" พร้อมโอกาสตอบคำถามรับโบนัส!

3. พิมพ์คำอธิษฐานที่หน้าหลักเพื่อปล่อยกระทงลอยในแม่น้ำได้

A หรือ ⬅️เลื่อนบล็อกไปทางซ้าย
D หรือ ➡️เลื่อนบล็อกไปทางขวา
W หรือ ⬆️หมุนบล็อก
S หรือ ⬇️เลื่อนลงเร็ว (Soft Drop)
Spacebarปล่อยตกทันที (Hard Drop)
Rเก็บ / สลับบล็อก (Hold)
Pพักเกมชั่วคราว (Pause)

* รองรับทั้งแป้นพิมพ์ภาษาไทย/อังกฤษ และปุ่มกดบนหน้าจอมือถือ
